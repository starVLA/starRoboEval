# First-two LIBERO visual code-agent development attempts

Both preselected LIBERO-10 tasks received one attempt, with released initial
state index 0, seed 20260907, fresh actor contexts and the same frozen prompt.
This is harness-development evidence, not a verified GPT/provider or full-suite
score. Provider model snapshot, request counts, tokens and cost are unavailable.

| Native task | Controlled steps | Decisions | First native success step / decision | Final native result | End reason |
| --- | ---: | ---: | --- | --- | --- |
| 0: alphabet soup and tomato sauce into basket | 180 | 37 | null / null | false | policy stop |
| 1: cream cheese box and butter into basket | 200 | 40 | null / null | false | decision budget |

The reference horizon was 520 (retained StarVLA evaluator setting), with at most
40 decisions and five executed actions per response. Task 0 returned 36 five-action
chunks followed by a stop; task 1 returned 40 five-action chunks. The ten fixed
initialization-settling actions per episode are not controlled steps or decisions.
All 180 and 200 controlled-step native-success entries were false. Visual partial
progress, moving above the basket, and submitting release commands do not award
native conjunctive-task success. No extra settling actions were appended after
the final response, and neither task was rerun to improve its outcome.

Closed originals are on eval under
`runs/libero-codeagent-first-two-20260907/case-000/run/` and `case-001/run/`.
Each run retains two camera videos, evaluator frames, action events and native
results; each case has a closed-log `progress.json`. First-success fields remain
`null` when no native success was logged, rather than being set to the final step.
