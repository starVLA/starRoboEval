## Interpretation and retained limits

Native Tabletop reward supplies `info.success` on every action. The adapter stops
at first native success; that declared stop rule is distinct from full-horizon
final-success parity. Neither pilot succeeded, so these records do not exercise
the successful stop path. The paired pilot has 2 completed attempts, 0 successes
and 0 errors; broader task coverage remains separate work.

Task19's constructor retained the missing `sketchfab/book` warning and upstream
skipped distractor configuration (`console.log:17–18`). The final explicit-reset
scene contains the target and source/target containers with validated dependency
closure. Inherited H200-to-eval inventory parity covers 42,994 files /
6,843,155,836 bytes; it does not establish the complete official asset release.
This audit rehashed the used scene assets and preserved that scope limitation.

The frozen prompt allows the actor's own same-episode memory. Each scheduled
request exports its current observation; the mailbox is not an OS sandbox or a
trusted provider-call meter. The offline artifact checks support the recorded
interface and accounting, not complete execution attestation or a named GPT score.
