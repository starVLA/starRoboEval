impossibility or full native-controller parity. A 36D joint/navigation policy
with only 100 ms per five-action prefix is a demanding control interface; any
future controller/action-budget change must create a separately frozen track,
not repair this failed result. Same-episode actor memory is allowed; the
mailbox's current-observation-only field describes payload delivery, not a
stateless or token-metered actor. Filesystem blinding is instructed rather than
